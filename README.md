# Sales Performance Dashboard Using Microsoft Excel

## Project Overview

This project focuses on analyzing sales data and developing an interactive Sales Performance Dashboard using Microsoft Excel 2019.

The dashboard provides insights into sales revenue, profit, order status, city-wise performance, product categories, and payment methods.

The objective is to transform raw sales data into meaningful business insights using Excel formulas, PivotTables, PivotCharts, and dashboard visualizations.

## Tools & Technologies

- Microsoft Excel 2019
- PivotTables
- PivotCharts
- Excel Formulas
- Data Analysis
- Dashboard Development

## Project Objectives

- Analyze overall sales and profit performance.
- Calculate important business KPIs.
- Compare sales performance across different cities.
- Analyze category-wise sales and profit.
- Evaluate order status and payment methods.
- Build an interactive dashboard for business reporting.

## Dataset Overview

The project uses a sales dataset containing approximately 500 records.

The dataset includes information such as:

- Order ID
- Customer ID
- City
- Segment
- Product Category
- Sales
- Profit
- Order Status
- Payment Method

## Business Analysis

### 1. City-wise Sales Analysis
Compared total sales across Delhi, Hyderabad, and Noida.

### 2. Category-wise Sales Analysis
Analyzed sales performance across Clothing, Electronics, and Furniture.

### 3. Order Status Analysis
Evaluated delivered and cancelled orders.

### 4. Payment Method Analysis
Compared customer order preferences across payment methods.

### 5. Profit Analysis
Evaluated profit performance across product categories and sales segments.

## Key Business Insights

- Furniture generated the highest sales revenue among the three product categories.
- Hyderabad generated the highest city-wise sales, followed closely by Delhi.
- COD was the payment method with the highest number of orders.
- Clothing showed strong profit performance compared with its sales revenue.
- Order status analysis helped identify delivered and cancelled orders.
